# Reboot to Code 💻

## Descripción
Landing page personal que presenta mi transición de técnico en reparación de PC 
a desarrollador front-end. Desarrollada como proyecto final del módulo de 
Flexbox de The Odin Project, replicando una estructura de diseño dada, pero 
con contenido propio en lugar de texto de relleno.

## Objetivo
- Practicar Flexbox para maquetar un layout
- Practicar HTML semántico
- Aplicar buenas prácticas de nomenclatura de clases (BEM).

## Demo
🔗 [Ver sitio en vivo](https://guidosaez.github.io/reboot-to-code/)

## Tecnologías
- HTML5
- CSS3

## Aprendizajes
- Entendí cómo combinar Flexbox en distintos niveles anidados (columna para 
  el layout general, fila para las secciones internas).
- Practiqué el uso de `flex-grow`, `flex-shrink` y `flex-basis` para controlar 
  qué elementos se estiran y cuáles mantienen un tamaño fijo.
- Reforcé la metodología BEM para nombrar clases de forma consistente.
